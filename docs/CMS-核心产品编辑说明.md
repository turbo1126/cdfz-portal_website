# CMS 核心产品编辑说明

## 进入后台

1. 重启 CMS：`pnpm dev:cms`
2. 打开 `http://localhost:1337/admin`
3. 进入“内容管理器（Content Manager）” → “核心产品”

## 字段说明

| CMS 字段 | 页面用途 |
| --- | --- |
| `title` | 首页卡片、产品列表和详情页的产品名称 |
| `slug` | 产品详情网址，例如 `ai-mediation-assistant`；发布后不建议随意修改 |
| `category` | 卡片标题上方的产品分类，例如“基层治理智能体” |
| `summary` | 卡片简介及详情页标题下方摘要 |
| `tags` | 卡片标签和详情页“核心能力”，每项单独添加 |
| `icon` | 卡片图标，可上传透明 PNG；未上传时使用默认图标 |
| `cover` | 详情页右侧头图；未上传时显示产品名称视觉标识 |
| `content` | 点击产品卡片后的详情正文，支持标题、段落、列表、链接和图片 |
| `sortOrder` | 排列顺序，从小到大显示，建议填写 `1`、`2`、`3`、`4` |
| `featured` | 是否在首页“核心产品矩阵”展示；关闭后仍会显示在产品列表页 |

填写完成后点击右上角“发布（Publish）”。只有已发布内容会显示在官网。

## 首次切换注意事项

CMS 没有已发布产品时，前端继续显示默认的四个产品。只要 CMS 发布了至少一个产品，首页和产品列表就会完全使用 CMS 中的已发布数据。

因此建议先创建完需要的全部产品，再统一发布。

## 推荐 slug

- AI 调解通：`ai-mediation-assistant`
- 视安盾：`vision-shield`
- 巡检小旋风：`inspection-cyclone`
- 房屋管理通：`housing-manager`

## 中英文内容

中文版发布后，可在语言区域创建 English 本地化版本。`sortOrder` 和 `featured` 为中英文共用；名称、分类、摘要、标签、图片和正文可以分别编辑。
